# ATM Interface 💳

A console-based **ATM Interface application built using Java** that simulates basic banking operations. This project demonstrates object-oriented programming, transaction management, and user interaction through a menu-driven system.

## 🚀 Features

- 🔐 **User Authentication** — Login using User ID and PIN.
- 🔒 **Login Security** — Limits incorrect login attempts.
- 💰 **Balance Management** — Check account balance before transactions.
- 💵 **Cash Withdrawal** — Withdraw money if sufficient funds are available.
- 🏦 **Cash Deposit** — Add money to an account.
- 🔄 **Fund Transfer** — Transfer money between accounts.
- 📜 **Transaction History** — View recorded banking transactions.
- 🚪 **Secure Exit** — Quit the application through the menu.

## 🛠️ Technologies Used

- **Language:** Java
- **Concepts:** Object-Oriented Programming (OOP), Classes, Objects, Encapsulation, Conditional Statements, Loops, and Exception Handling
- **Data Structures:** `ArrayList`
- **IDE:** IntelliJ IDEA
- **Version Control:** Git and GitHub

- Java JDK installed (JDK 8 or later, depending on the APIs used).

## ▶️ How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/sonu-codes-maker/OIBSIP-Java-Development-ATM-Interface.git
   ```

2. Open the project in IntelliJ IDEA.

3. Ensure the JDK is configured.

4. Open `src/Main.java`.

5. Run the `Main` class.

6. Follow the on-screen instructions to log in and perform ATM operations.
